每份图集小于100,000字节；192像素档、64色共享调色板、无抖动、最近邻过滤。原始素材在`art-source/vfx/`，坐标/哈希在`resources/vfx-ready/*.json`。运行清单由`npm run assets:pixel-vfx`生成到`src/pixel-vfx-manifest.ts`。

打包器仅复制清单中明确启用的PNG，逐项核对哈希与100 KB上限；原图、实验候选与对比文件不发布。三张新图合计110,329字节，首局包包含这些字节，不将按需解码误报为减少下载。当前约主包0.878 MiB、首局8.080 MiB，以`size-report.json`为准。

## 加载和复用

- 进入升级或商店时预热当前选项所需图集，不在启动阶段解码全部技能图片。
- `EffectAssets`统一管理火焰、冰环、梦弹与绽放图集；同图集共享加载Promise与GPU纹理，批次各自拥有材质和缓冲。并发请求去重，失败清除请求缓存以支持重试。
- 用户确认技能/购买时，所需图集未就绪则进入“准备技能”状态，停止模拟时间、移动与攻击；完成后才确认原操作。商店仍按原版本凭据验证，加载取消不扣金币或消耗升级选择。
- 宝箱自动奖励也检查新获得的技能依赖；每个固定步开始前及波次边界授予后、战斗模拟前均接入资源门禁。
- 准备失败可重试。升级/商店来源取消后回到原界面；自动奖励已改变构筑时取消准备会返回营地，不带着缺图技能恢复战斗。
- 切后台、窗口变竖屏或音频中断时，准备完成也不自动恢复战斗；退出/重开使旧的异步确认失效。
- 重开清空原战斗对象池中的技能状态，已解码图集按预算保留复用；当前构筑与待确认操作持有引用，无引用缓存可释放。只读诊断`skillResources`区分下载/解码/纹理准备状态与预算，`skillEffects`保留原技能诊断，不提供改数值接口。

## 渲染边界

`src/skill-vfx.ts`将冰环、绽放与梦印的模拟状态转换为绘制参数，梦弹主体和接触反馈由`src/projectile-vfx.ts`处理。通用图集实例实现位于`src/render/vfx/atlas-batch.ts`，帧UV和淡出透明度使用实例属性；容量沿用原冰环2、梦系事件64、投射物24。代码像素轮廓与轨迹分别位于`src/render/vfx/pixel-batch.ts`、`trail-batch.ts`，火焰扇形位于`sector-wave.ts`。纹理由`src/assets/effect-assets.ts`唯一管理，材质和几何不随每次施法创建。

冰环空心与边缘遮罩、梦系边缘柔化和中心透明度沿用原表现规则；绽放按`event.age / event.duration`选择8帧。绯梦弹以原10 FPS循环，朝向随速度，原先的通用球体不重复叠加。伤害、Boss/精英系数、叠印与三层触发均继续由`src/core/`决定。

基础子弹、拖尾和命中特效现已开发接入，下一开发阶段逐家族扩展元素武器。按用户最新要求，当前暂不执行测试、类型检查、构建或模拟器，验证结果另行记录。
