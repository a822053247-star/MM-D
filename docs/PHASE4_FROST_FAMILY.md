## 胶囊范围与真实命中

原冰川滑痕命中计算先将敌人位置变换到 patch.angle 的局部坐标，再计算到固定线段的距离。它是胶囊形，不能用圆形或任意长条代替。

本批将原固定直线半长提取为 `ICE_LIMITS.trailHalfLength`，数值保持不变；碰撞和绘制共用它。`CapsuleBatch` 使用同一半长、patch.radius 与 patch.angle 计算圆角端部与轮廓。碰撞仍按原规则加上目标自身半径，绘制不修改该判定。

移动距离触发、停止移动不生成、池满替换、区域重叠跳伤约束、伤害与障碍遮挡均保留原实现，没有新增滑行、地形碰撞、减速区域规则或独立计时器。

## 文件和所有权

- `src/core/projectile-presentation.ts`：霜晶接入既有的实际接触/撞墙/消散事件池，仍排除带融合配方或自定义表现的兼容弹体。
- `src/content/projectile-recipes.ts` / `projectile-vfx.ts`：增加霜晶表现参数；将各弹体消散形状和中心闪光放入配方，避免每加一个元素就扩充渲染分支。
- `src/render/vfx/pixel-batch.ts`：共享晶片与雪花轮廓，不新建位图纹理。
- `src/render/vfx/capsule-batch.ts`：固定容量胶囊区域绘制，明确区分填充与轮廓；方向、范围来自调用数据。
- `src/content/frost-recipes.ts` / `frost-vfx.ts`：统一霜寒、冻结、抗冻、解冻、范围命中与冰川区域的表现。
- `src/core/frost-combat.ts`：只增加表现事件来源标签，并将原表现寿命提取为共享常量，保留原数值。区分 projectile/area/status：霜晶弹接触由 ProjectileVfx 绘制；范围命中与状态事件由 FrostVfx 绘制，避免重复接触闪光。
- `src/core/ice-skills.ts`：仅提取原胶囊直线半长，碰撞值不变。
- `src/water-vfx.ts`：移出冻结标记，继续拥有湿润/水系减速标记；冻结不再由两个视图重复绘制。
- `src/view.ts` / `main.ts` / `model.ts`：接入初始化、逐帧读取、重开清理、共享细节档及只读 frostEffects / skillEffects.frost。
- `src/content/enabled.ts` / `effect-recipes.ts`：登记两个新开放 ID 和必要表现，沿用统一奖励名单与准备门禁。

## 容量与生命周期

本批沿用 24 颗共享投射物、24 块冰川区域和 48 个 FrostCombat 事件。冰川轮廓/铺底固定 48 实例，装饰晶片 96 实例；冻结冰沿最多 256，状态标记最多 1,024，范围/状态碎屑最多 240。水系状态容量调整为 512，负责湿润与水系减速。

full/reduced 保留相同的霜晶主体、穿透弹体、胶囊轮廓、冻结/霜寒/抗冻状态；只减少区域装饰晶片、事件碎冰、轨迹与光晕。装饰池容量不影响真实伤害或状态判定。敌方危险预警仍处于更高绘制顺序。

状态计时、事件年龄和 patch 寿命全部来自原模拟。暂停、升级、商店与资源准备不推进；原 clear/reset、敌人复用清理和视图 reset 沿用。没有新增纹理下载、独立 RAF 或按命中创建 GPU 对象。
