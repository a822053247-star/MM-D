| ID | 内容 | 实际表现来源 |
|---|---|---|
| `abyss-vortex` | 深渊漩涡 | 固定位置、真实半径的圆形领域，向内收束的装饰水滴与涟漪；敌人是否移动完全由原规则决定。 |

## 实现与规则边界

`src/core/position-aoe.ts` 的拉动、目标选择、周期伤害、同类足迹重叠约束、光束判定、往返账本、回程中心变化和经验球吸引保持原算法。此次只增加固定表现池，并提取原光束起始距离/半宽/蓄力时间、圆环蓄力和环带常量，保留原值，供绘制共享。

新增 96 槽环形反馈池：原 hit 调用后记录目标位置，原经验球由未吸引变为吸引的分支记录 orb-pull。记录不增加伤害、经验值或随机调用；池满只覆盖最旧表现，不影响结算。经验球移动与领取继续由原模拟处理。

### 具体几何

- 漩涡与孢火足迹使用圆形区域，但采用不同配色和装饰流向；保留真实场地边界，不添加原规则不存在的障碍遮挡或中毒状态。
- 光束使用有限矩形 StripBatch，从原 rayStart 延伸到 cast.radius，宽度为原 rayHalfWidth 的两倍。先显示蓄力轮廓，原 fired 置位后显示放电；不会用一整片圆盘覆盖束间空隙。
- 冰棱圆环和潮汐水浪直接读取 ringRadius，不用动画进度重新计算半径。显示原环带宽度，去程/回程使用不同明度；碰撞仍保留原前一状态到当前状态的扫掠算法。
- 回程中心读取 cast.x/z，不追踪或修改角色来另算一套返回轨迹。吸引星光只表示原磁吸状态刚被触发，不表示额外经验奖励。

## 文件入口

- `src/content/position-recipes.ts`：四技能的色彩、铺底、高度与装饰细节档。
- `src/render/vfx/strip-batch.ts`：共享有限直条的填充/轮廓绘制，固定材质、几何和缓冲；与曲折雷电分开，保留真实矩形范围。
- `src/position-vfx.ts`：组合 AreaBatch、StripBatch 与 PixelBatch，读取原 PositionAoe.casts 和只读反馈数组。
- `src/core/position-aoe.ts`：共享原几何常量和新的只读环形表现输出；原玩法算法保留。
- `src/content/enabled.ts` / `effect-recipes.ts`：四 ID 进入统一正式支持、依赖与资源门禁。
- `src/view.ts`：初始化、绘制、细节档和重开批次清理。
- `src/main.ts` / `model.ts`：只读 positionEffects、skillEffects.position 诊断，原技能名称、简述和成长说明继续由 progression 提供。

## 容量、质量与生命周期

原施法池共 22 槽：漩涡 2、冰棱放射 2、足迹 16、潮汐回收 2；每个放射施法最多 16 条光束。新增绘制固定容量为：范围 64 实例，光束与可选亮芯 64 实例，场地装饰 176 实例，命中/吸引碎光 384 实例。表现拥挤不改变原施法容量或结算。

full/reduced 均保留所有有效场地、真实半径、每条光束、束间空隙和实际环带。reduced 仅减少场地装饰、反馈碎片、内层装饰涟漪和光束亮芯；不会把 16 条光束缩为 8 条。敌方危险预警仍处于更高绘制顺序。

所有动效使用原 cast.age 或反馈池年龄，没有独立 RAF/定时器。暂停、升级、商店和资源准备不推进模拟；反馈池跟随原 clear/reset 清空，足迹和回收水浪不跨局保留。没有按施法或命中创建 GPU 对象。
