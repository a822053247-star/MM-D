# 第三阶段：基础子弹与打击反馈

日期：2026-10-26。对应 plan.md 的 P2。状态：开发已接入，按用户要求未执行测试、类型检查、构建、浏览器或模拟器；画面、打击感、性能和包体尚未验证。

## 本批表现

| 子弹 | 主体 | 拖尾 | 命中与消散 |
|---|---|---|---|
| 火花弹 | 暖色像素火焰轮廓、亮色火芯和轻微闪动；显示大小随实际弹体半径缩放 | 短橙色轨迹 | 扫掠接触位置散开火星，撞墙/寿命结束时收缩为余烬 |
| 飞叶弹 | 尖叶轮廓、叶脉和轻微摆动，朝向跟随实际速度 | 较细、较短的绿色轨迹 | 每次真实穿透接触散出碎叶，寿命结束时叶片淡出 |
| 绯梦弹 | 复用原四帧图集、10 FPS及尺寸关系；纹理暂不可用时仍显示星形主体 | 粉色轨迹 | 接触产生星屑，撞墙/寿命结束时星光淡出；原梦印、绽放、回响仍读 DreamCombat |

火花弹与飞叶弹使用代码绘制的像素轮廓，共用 PixelBatch 的几何、Shader 和固定缓冲；火星、碎叶及星屑复用同一实现，没有新增位图纹理。这是本批采用的表现资源方案，不代表迁入了原项目的完整火焰动画图集。梦弹继续使用第二阶段的统一纹理缓存。

正式奖励名单没有扩展；正式模式仍为火焰横扫起手，三种弹体通过现有升级/商店资格获得。练习模式的火花弹也使用新表现。没有改变射速、飞行速度、寿命、命中半径、伤害或升级规则。

## 数据链路和接入点

- `src/core/projectile-presentation.ts`：96 槽环形表现事件池，提供不复制的只读数组视图；记录 attack、impact/wall/expire、实际位置、模拟时间、速度和半径。池满覆盖最旧表现事件，不增加伤害或改变命中。
- `src/core/combat.ts`：在现有普通/元素扫掠接触、撞墙及寿命结束处分发事件。接触位置继续使用原碰撞计算的插值结果；表现事件不调用随机函数，不参与资格、伤害和奖励判定。
- `src/content/projectile-recipes.ts`：集中三种弹体的轮廓、颜色、显示尺寸、拖尾长度、反馈寿命、碎片数量和细节档参数。
- `src/content/effect-recipes.ts` / `enabled.ts`：为已开放火花/飞叶登记无需下载图集的像素表现配方，梦弹继续依赖已有图集，发布 PNG 清单没有扩展。
- `src/render/vfx/pixel-batch.ts`：统一代码像素轮廓、实例颜色/透明度及矩阵缓冲，不按每颗弹体创建 GPU 对象。
- `src/render/vfx/trail-batch.ts`：每个实际投射物槽保存最多六个固定步位置，长度与寿命双重限幅；用出生 tick、来源 rootId、代数与年龄回退识别槽位复用。
- `src/projectile-vfx.ts`：组合主体、梦弹图集、拖尾及反馈批次；读取真实池状态和事件，只输出绘制。
- `src/main.ts` / `view.ts`：每个模型固定步后采样轨迹，每帧绘制一次。原通用球体只负责本批未接管的弹体，避免三种基础弹体重复叠加。
- `src/skill-vfx.ts`：继续处理冰环、梦印、绽放和回响；梦弹主体及普通接触碎光已交给 ProjectileVfx，避免两套实现重叠。

事件 impact 表示实际扫掠接触，不等价于“必定扣血”。免伤和捕捉等资格仍由原伤害入口决定，本批不根据表现推断伤害或显示虚构伤害结果。带已有融合 ID、配对配方或自定义 VFX 的弹体不由本批接管，保留原兼容路径，后续融合阶段再迁移对应表现。

## 容量、暂停和细节档

| 项目 | 固定容量/策略 |
|---|---|
| 主体 | 24 颗实际投射物；代码轮廓最多 48 实例，梦弹图集最多 24 实例 |
| 轨迹 | 每槽六点，最多 120 段实例；逐固定步采样，不用渲染位置推算历史 |
| 接触与消散事件 | 96 槽环形池，仅在实际事件发生时写入 |
| 反馈绘制 | 最多 576 实例，独立于主体容量，装饰拥挤不挤掉有效子弹 |
| full | 最多五段拖尾、五片碎屑和中心星光 |
| reduced | 最多两段拖尾、两片碎屑，移除中心装饰；主体/亮芯/实际弹体数量不变 |

`GameView.setEffectDetail('full' | 'reduced')` 提供细节档接入，启动读取本地 `mm-douyin-effect-detail`，默认 full。本批没有新增设置菜单或自动设备分档，不把该接口描述为已完成玩家设置界面。

轨迹和反馈年龄使用战斗模拟秒数，暂停、升级、商店和资源准备不推进。重开与 clearTransientEffects 更新表现 epoch 并清空事件，轨迹同步清空；不会跨局连接。消失事件使用碰撞/寿命结束的最终坐标，飞叶穿透命中不隐藏仍然有效的主体。敌方预警没有接入装饰质量缩减。
