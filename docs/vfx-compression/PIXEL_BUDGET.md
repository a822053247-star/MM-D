# 每份特效图集小于100 KB

本批按可爱像素游戏方向重新处理冰环与梦系爆发。所有原始图保留，采用PNG发布候选，无需WebP解码器或更换引擎。

预算按**100,000字节**计算，比100 KiB更严格。这里指一份包含全部动画帧的特效图集，不是每帧各100 KB。

| 特效 | 原始PNG | 推荐运行图集 | 帧数 | 处理方式 |
|---|---:|---:|---:|---|
| 火焰横扫 | 157,110字节 | **25,286字节** | 3个实际使用帧 | 原128像素帧无损提取，已接入 |
| 冰环 | 2,080,070字节 | **36,138字节** | 6帧 | 最大边192像素，64色统一RGBA调色板 |
| 梦系爆发 | 2,145,759字节 | **53,277字节** | 8帧 | 最大边192像素，64色统一RGBA调色板 |
| 绯梦弹 | 原始独立图集 | **20,914字节** | 4帧 | 最大边192像素，64色统一RGBA调色板 |

推荐版本保留更多轮廓与碎片细节，同时提供更省的128像素版本：冰环19,214字节，梦系27,634字节。所有版本均关闭抖动，按整个动画共享调色板，避免各帧独立减色造成闪色；缩小与减色会改变原像素和半透明层次，这是像素风重制，不能称为对原图无损压缩。

## 文件与复用

- 推荐PNG及逐帧坐标：`resources/vfx-ready/ice-ring.png/.json`、`resources/vfx-ready/dream-bloom.png/.json`。
- 128像素等候选：`resources/vfx-samples/*.pixel-*.png`，不进入部署包。
- 精确字节数、来源哈希与候选配置：本目录`pixel-report.json`。
- 冰环对比：[原图与推荐版](ice-ring-pixel-comparison.png)、[完整6帧](ice-ring-pixel-frames.png)、[动画预览](ice-ring-pixel-preview.gif)。
- 梦系对比：[原图与推荐版](dream-bloom-pixel-comparison.png)、[完整8帧](dream-bloom-pixel-frames.png)、[动画预览](dream-bloom-pixel-preview.gif)。

执行`npm run assets:pixel-vfx`可重新生成，使用本地Python/Pillow。普通构建直接使用已生成文件，无需执行压图。

帧数、帧序、原始帧窗口和播放时序说明全部保留；图集增加2像素边缘外扩，元数据记录源尺寸与新UV坐标。梦系GIF仅以100毫秒/帧示意，未来接入仍按原cast.duration归一化播放。

## 使用状态与预算检查

火焰、冰环、绯梦弹与梦系绽放已接入。冰环/绯梦弹可在六波闯关升级或商店获得，绯梦弹三层梦印触发绽放，绯樱回响按原资格出现。三份新增图集合计110,329字节，随首局分包下载，使用前按需解码并共享缓存；具体见[接入说明](../SKILL_VFX.md)。

`config/vfx-budget.json`保存100,000字节硬上限。生产构建同时检查已准备与已发布的特效图集大小、文件哈希，超限或文件/元数据不一致会失败。原图、实验候选、对比图与GIF不受运行图集预算约束，也不进入部署包。

本批仅做资源生成、静态图像复核、类型检查与生产构建；未运行浏览器、模拟器或真机测试。后续新增复杂特效优先采用这种像素图集；超过预算时按分辨率/颜色候选回退，不悄悄删除动画帧。
